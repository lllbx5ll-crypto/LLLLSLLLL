# مدينة التجار | Merchants City 3D

**Developer: Al-Qmishi**

Arabic-first 3D open-world trading and life simulation for Android. Built with Godot 4.7.2 and GDScript (free open-source engine; suitable for GitHub Actions Android builds without a commercial Unity license).

> ⚠️ Work in progress. The first delivery is a **playable prototype**, not a finished photorealistic city or commercially polished game. Expect new systems and assets to be developed and tested iteratively.
