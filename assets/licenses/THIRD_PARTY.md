# Open-source assets and licenses

All **Kenney** 3D game models imported by `ci/install_assets.py` originate from [Kenney's asset packs](https://kenney.nl/assets), distributed under **Creative Commons Zero (CC0 1.0)**. Their packaged glTF versions are from [Hidencod/tge-assets](https://github.com/Hidencod/tge-assets) pinned to commit `3ddcc695adbba9fb918cf31b7c139b3f95b76910`.

- Models: CC0 1.0; unrestricted use including commercial games.
- Arabic font **Noto Naskh Arabic** by Google: SIL Open Font License 1.1, with OFL text in `assets/licenses/OFL-NotoNaskhArabic.txt`. Its font file is not to be renamed to a Reserved Font Name; font redistribution should retain license.
- Developer/game code and original authored assets: © Al-Qmishi, see project root.

These assets substantially improve the placeholder geometry but **are still stylized low-poly models, not photorealistic people or a completed AAA city**. Authentic ambient audio and realistic character animation are a later licensed-assets production milestone.

## Audio additions

- Kenney UI Audio: original sound effects, CC0 1.0, sourced from [Calinou/kenney-ui-audio](https://github.com/Calinou/kenney-ui-audio) pinned commit `8c3d81b9159d058c444f89d12d518276b0b09345`. Included WAV clips are real audio files, not in-game synthesized beeps.
- Three **field-recorded** CC0 audio layers (post-processed): crowd by psykophobia, road ambience by klau78, and cafe by arpeggio1980. Redistribution from [euuuuuuan/todak-public](https://github.com/euuuuuuan/todak-public) pinned at `f298bf5d4fa9a0f1552ce8ca437ea1d940b42d4f`, provenance in its [CREDITS.md](https://github.com/euuuuuuan/todak-public/blob/main/CREDITS.md). These are ambient recordings, **not** Arabic dialogue or voice acting.

- **Cairo Arabic UI font**, Google Fonts project, SIL OFL 1.1, embedded in APK with license at `assets/licenses/OFL-Cairo.txt`. https://github.com/google/fonts/tree/main/ofl/cairo
- **Kenney RPG Audio footsteps** `footstep00/02/06/09.ogg`, CC0 1.0. Copied from [euuuuuuan/moonshard-warden-public](https://github.com/euuuuuuan/moonshard-warden-public) (pinned commit `897d26af64aab4003b057b3910a7118279b927d8`), source Kenney RPG Audio.
